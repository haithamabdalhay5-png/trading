# مِرصد — منصة مراقبة وتحليل التداول

نسخة تأسيسية مبنية بـ **Next.js App Router + TypeScript**. المستودع لا يحتوي بيانات مفاتيح أو أوامر تنفيذ صفقات. الواجهة تعرض حالة التغذية فقط، ولا تقدم توصيات مالية في هذه المرحلة.

## ما يعمل الآن

- لوحة مراقبة عربية RTL مع تحديث حالة كل 5 ثوانٍ.
- `POST /api/ingest` لاستقبال حزمة MT5، محمية بترويسة `Authorization: Bearer <MT5_INGEST_TOKEN>`.
- تحقق من JSON، وقت UTC، أسماء الأدوات، Bid/Ask، تكرار الرمز، وحجم الحزمة (256KB كحد أقصى).
- آخر لقطة عبر Upstash Redis، وسجل تاريخي اختياري عبر Supabase.
- `GET /api/market/latest` يعرض آخر لقطة ومؤشرات حالة الاتصال/حداثة البيانات دون كشف الأسرار.
- أولوية البيانات لـ MT5 المباشر؛ عند غياب لقطة MT5 حديثة يُقرأ ملف Drive الاحتياطي ويُتحقق من مخططه. يُحدّث cache Drive في Redis مرة كل 50 ثانية كحد أقصى، والبيانات الأقدم من 90 ثانية تُعلّم قديمة ولا يجوز استخدامها لاتخاذ قرار.
- عند فشل الكتابة إلى Supabase بعد حفظ Redis، ينجح استقبال اللقطة الحية ويعاد تحذير `history: failed`؛ راقب السجلات قبل الاعتماد على التخزين التاريخي.

## تشغيل محلي

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

أضف القيم محليًا إلى `.env.local` أو إلى إعدادات البيئة في Vercel. لا تضع أي قيمة سرية داخل GitHub أو داخل كود الواجهة. أنشئ رمز MT5 عشوائيًا طويلًا (32 بايت على الأقل)، واحفظه في الخادم وفي إعدادات EA/MT5 فقط.

## واجهة حزمة MT5 الحالية

تمت مطابقة `src/lib/market-schema.ts` مع عينة `Schema 2.1` المرسلة. الهيكل الفعلي يستخدم `commodities` كخريطة مفاتيحها رموز الأدوات، وليس مصفوفة `symbols`:

```json
{
  "schema_version": "2.1",
  "utc_timestamp": "2026-11-23T20:50:57Z",
  "server_utc_offset_hours": 2,
  "target_strategy": "DayTrading",
  "intermarket": { "dxy_price": 104.361, "dxy_change_pct": 0.54, "xau_xag_ratio": 84.43 },
  "commodities": {
    "XAUUSD": {
      "meta": { "symbol": "XAUUSD", "bid": 3633.11, "ask": 3633.25, "spread_points": 14 },
      "basis": { "futures_price": 3646.11, "basis_spread_usd": 13.0 },
      "quant_regime": { "hurst_m15": 0.515, "detected_regime": "NOISE" },
      "candles_data": { "M5": [{ "t": "2026.11.23 20:50", "o": 3651.76, "h": 3654.65, "l": 3650.31, "c": 3651.56, "v": 2256 }] }
    }
  },
  "diagnostics": { "processing_time_sec": 0.422, "status": "OK" }
}
```

العينة المرفقة بحجم يقارب 42KB وتضم XAUUSD وXAGUSD وXPTUSD وخمس درجات زمنية (15–40 شمعة لكل إطار)، وهي ضمن حد الاستقبال الحالي 256KB. تم التحقق برمجيًا من الحقول الأساسية، السعر والسبريد، المؤشرات، مستويات السيولة وSMC، شموع OHLCV، والحقول الاختيارية التي قد تكون `null` مثل الفارق الآجل.

تُحفظ الحزمة الأصلية كاملة في التخزين؛ لتقليل استهلاك Gemini لاحقًا، لن نرسل هذا الـ JSON كاملًا لكل وكيل: سننشئ لكل تحليل حزمة مختصرة من المؤشرات المطلوبة وآخر 12 شمعة فقط.

## مسار التنفيذ

1. **الاستقبال والتخزين:** جسر MT5، تحقق/مصادقة، Upstash، ومخطط Supabase. معيار القبول: استقبال الحزمة الحقيقية وإظهارها في اللوحة.
2. **الوكلاء والقاضي:** Gemini بشكل متوازٍ بمخرجات مهيكلة، الوكيل المعارض، أوزان متغيرة، حسابات حتمية، وبوابات فيتو. لا يبدأ قبل تثبيت عقد البيانات وحدود القرار.
3. **التشخيص والمعايرة:** الأخطاء، spread/news/staleness vetoes، إدارة المخاطر، حاسبة حجم العقد، وسجل تدقيق قابل للتصدير.
4. **التنبيهات والسجل:** تيليجرام عند تغيّر القرار فقط، سجل Supabase، وقياس معايرة الوكلاء. لا تنفيذ صفقات آلي في النطاق الحالي.

## متغيرات البيئة

راجع `.env.example`. اضبط `GOOGLE_DRIVE_FILE_ID` على معرّف ملف `COMMODITIES_QUANT_DATA.json` (المعرّف الحالي موجود في المثال)، إضافة إلى متغيرات Upstash المطلوبة لتخزين cache والتحكم في معدل القراءة. يجب استخدام مفتاح Supabase للخدمة في الخادم فقط؛ لا تستخدم مفتاحًا عامًا لكتابة سجل تاريخي حساس. رابط Drive الحالي قابل للتحميل لمن لديه الرابط؛ لا تغيّر إعدادات المشاركة إلا إذا قررت ذلك بنفسك.

## ما نحتاجه منك لإكمال الربط بأقل جولات

العينة كافية لتثبيت عقد البيانات، ولا حاجة لإرسالها مرة أخرى. الخطوة التالية هي توصيل مصدر الإرسال والتخزين:

1. أرسل ملف EA/Exporter بصيغة `.mq5` أو الصق جزء `WebRequest` إن كان موجودًا؛ لأضيف إليه الإرسال الآمن كل 5 ثوانٍ إلى `/api/ingest`. إذا لم يوجد، قل: **«لا يوجد إرسال بعد»**.
2. إذا كانت الرموز الفعلية لدى الوسيط تحمل لاحقة (مثل `.m`) أخبرني بها؛ العينة الحالية تستخدم أسماء قياسية.
3. أضف `GOOGLE_DRIVE_FILE_ID` وبيانات Upstash (`UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`) وSupabase (`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`) و`MT5_INGEST_TOKEN` إلى إعدادات Vercel. لا ترسل القيم السرية في المحادثة. ملف Drive الاحتياطي لا يغني عن إعداد Upstash؛ Redis يخزّن آخر نسخة ويمنع تنزيل Drive مع كل تحديث للوحة.
4. مرحلة الوكلاء لا تحتاج قرارًا منك الآن؛ قبلها سنثبت مزود الذكاء الاصطناعي وحدود السبريد والمخاطرة وقيود الأخبار.
